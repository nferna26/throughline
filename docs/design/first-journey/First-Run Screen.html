Interaction note

Where it lives: the code entry sits on this first-run screen, just under the reading actions, separated by a hairline so it reads as secondary. It is also kept in Settings for later. A free or open-source reader can ignore it entirely and just open a book.

How it expands: clicking "Enter your code" replaces the one-line affordance in place with the mono field, helper line, and Activate, no modal, no navigation. "Not now" collapses it back to the resting line.

After success: the field becomes the confirmation banner ("You're activated. Welcome in."). The rest of the screen stays, so the reader still picks a book; the tutor is now lit in the margin once they're reading. This is the same banner the deep link shows, so throughline://activate buyers and manual-entry buyers land on an identical confirmation.

Reading is never gated: activation only enables the included tutor (~400 explanations, then bring-your-own-key or local). The covers, Browse, and Import all work with no code and no account.

Repoint flag: the "enter your code in Settings" line now has a more obvious home. Update the fulfillment email, the FAQ, and the success page to point here, e.g. "open Throughline and enter your code on the welcome screen." Keep Settings working as the later path.

4

What craft I raised

reference pass
Covers
The hero got the most care. Each is now a real cloth-bound object: a spine ridge and inner shadow on the left edge, a faint cloth weave, a gilt inner frame, and letterpress titles (a hair of deboss). Deeper grounding shadows sit them on a shelf; they lift on hover. Tactile enough to want to touch, the Apple Books lesson without cloning it.
Type
Tighter display tracking and leading on the serif headline (optical sizing on), a measured 15-character line, and a calm sans lede at a comfortable measure. The Things 3 / iA Writer standard: nothing shouts, every value considered.
Rhythm
More confident whitespace between hero, shelf, actions, and the hairline above the code whisper, so the screen breathes like a well-kept bookshop, not a form.

Clear of every Matter anti-pattern

One calm screen, no multi-step funnel. No streaks, daily goals, "X books a year," or habit framing. No aspirational-pressure or guilt copy, it invites, never pressures. No quizzes, occupation or topic pickers, or "favorite thinkers." No account, sign-in, magic link, trial, or paywall. No line-drawing mascots. Warm paper is home; dark is warm, not black. The covers are the welcome; the code is a whisper at the bottom, never a gate.

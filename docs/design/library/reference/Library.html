Throughline · the library

The books you've started, kept calm

Where a reader sees the books they're reading, honors the ones they've finished, and removes what they no longer want. One unified shelf, never a backlog or a collection to maintain. A book lands here only when you start it, so the library is always books you chose to read, never a pile of obligation.

One shelf, quiet provenance

Catalogue and imported books live together. The cover carries the source, no two visual classes, no badges on the shelf.

Nothing to maintain

Active book first, then reading and finished. No tags, folders, ratings, or want-to-read. Search arrives only when the shelf outgrows a screen.

One calm verb

Remove from library deletes Throughline's copy and reading state. It never touches your original file. There is no "delete file."

3

Remove from library

two calm confirmations · undo

One verb. The confirmation is stakes-honest, not alarming, and it differs by source because the loss differs: a catalogue book is cheap to re-add, an imported book's reading state is the real thing being deleted. Neither ever touches the reader's original file, and there is no "delete file" anywhere. A brief undo restores the reading state if it was a slip.

Catalogue book · light loss · light

Remove Meditations?

It leaves your library. You can add it back from the catalogue anytime, free.

Your reading plan and notes for it will be cleared.

Imported book · names the real loss · dark

Remove Sapiens?

Your reading progress, notes, and tutor history for it will be deleted.

Your original file isn't affected, it stays wherever you keep it, and you can import it again.

Should a cloth fallback for an import look different from a catalogue cloth cover? Only barely. They share the treatment so the shelf stays unified; the one quiet difference lives in the book's detail view, where an imported book reads a small italic "Imported · your file" line and a catalogue book reads "From the catalogue." The moved-file edge · calm · light

A Field Guide
M. Rivers

Still here, still readable

Looks like the original file for this book moved. Throughline keeps its own copy, so your reading isn't affected. You can point it at the file again if you'd like.

Because Throughline holds its own copy, a "dangling" import is never broken, reading continues. So this is a quiet, dismissible offer in the book's detail view, not an error and never a shelf-wide alarm. Re-link just re-associates the original for future re-export; "Leave it" is completely fine.

The one-time data-folder moment · dark

Everything lives in one folder

Your books and notes are kept here on this Mac. Catalogue books re-download anytime, so there's nothing you must back up. If you'd like a copy, this is the folder to save.

~/Library/Throughline

Shown once, the first time a reader imports their own file (catalogue-only readers never need it). It states where things live and that catalogue books need no backup, then never returns. No recurring "back up now" guilt, no badge, no nag.

5

Open questions, resolved

decisions

The provenance signal

The cover reality carries it. Imported books show their real embedded cover; catalogue and cover-less imports wear the cloth cover. The only words ("Imported · your file" / "From the catalogue") live in the book's detail view. No shelf badges, no two visual classes.

Finished books

They stay on the same shelf, in a quiet "Finished" section below "Reading." Honored with a small letterpress check on the cover, no trophy case, no count celebrated, no streak. Completion is marked, never rewarded into collecting.

Where Remove lives

Primarily in the book's detail view, and reachable by right-clicking a book in the switcher or on the shelf. Never a row of delete buttons sitting out on the shelf inviting the act.

When search appears

Once the shelf outgrows roughly one screen (~16 books). A single "Find a book in your library" field joins the header; nothing else changes. No sort, no filter, no maintenance, ever.
